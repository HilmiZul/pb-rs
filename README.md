# PocketBase-Rust (pb-rs)

A Rust rewrite and port of PocketBase, built as my first experiment with Agentic AI. I built this purely for my personal side projects because I love how simple, lightweight and fast PocketBase is.
Special thanks to Gani Georgiev for creating the original project.

## Upstream

Check out the original [https://ganigeorgiev.com/pocketbase/pocketbase/releases](https://ganigeorgiev.com/pocketbase/pocketbase/releases)

## Build

```sh
cargo build --release
# binary: target/release/pocketbase
```
